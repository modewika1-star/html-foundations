A personal Arabic HTML page created as an early frontend learning exercise, combining text, links, media, and basic HTML formatting.

</div>

## ✨ What is included

- An Arabic introduction about starting a frontend learning journey.
- Headings, paragraphs, lists, and text highlighting.
- A reference link to a YouTube video.
- An embedded local video element.
- HTML subscript and superscript examples, including a chemistry equation and Einstein's equation.

## 🛠️ Built with

- HTML5
- Native browser elements for links and video

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t1.git
cd t1
~~~

Open `index.html` in a browser. Keep the referenced video file beside the HTML file so the embedded media can load.

## 📚 Learning focus

This page is an early practice project for learning semantic structure, text formatting, lists, links, and embedding media in HTML.
